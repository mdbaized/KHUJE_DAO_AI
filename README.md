# KHUJE DAO AI

AI Powered Lost and Found Platform.

## Project Architecture

- Frontend: React + Vite
- Backend: Django + Django REST Framework
- Database: PostgreSQL + pgvector
- AI Service: Python (Future Phase)

## Applications

### Frontend

React application for user interface.

### Backend

Django REST API for business logic and data management.

### AI Service

Separate AI application for intelligent item matching.
